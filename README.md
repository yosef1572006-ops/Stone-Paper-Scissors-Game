# Stone-Paper-Scissors Console Game (C++)

A classic *Stone-Paper-Scissors* console game built in *C++, applying **Functional Programming* principles, clean code architecture, Enums, and Structs.

## Features
- *Customizable Rounds:* Play between *1 to 10* rounds per game session.
- *Dynamic Console Feedback:* 
  - Green Screen when the Player wins a round.
  - Red Screen + Alert Sound when the Computer wins.
  - Yellow Screen on a Draw.
- *Detailed Summary:* Displays round-by-round results and a final *Game Over* scoreboard.
- *Replayability:* Option to reset the screen and play again seamlessly.

## Built With
- *Language:* C++
- *Paradigm:* Functional Programming (Divide & Conquer)
- *IDE:* Visual Studio
